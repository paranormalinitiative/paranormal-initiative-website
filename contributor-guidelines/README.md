# Contributor Writing Guidelines

The Paranormal Initiative publishes research papers, field articles, experimental reports, technical notes, research notes, case and location studies, and review papers focused on paranormal investigation, EVP, ITC, consciousness, anomalous experience, equipment, methodology, ethics, and evidence review.

Contributions should be serious, readable, clearly documented, and honest about limitations. The goal is not to force every contributor into the same academic format. The goal is to help each piece land in the clearest form for what it is trying to do.

## Flexible Format Standard

Different people write in different ways. Some contributors may write full papers. Others may submit field notes, equipment observations, EVP session reports, review essays, location studies, technical explanations, or shorter documented ideas.

That is acceptable. The submission type is a guide, not a judgment of value.

When a contribution could fit more than one category, choose the primary purpose:

- If it explains a topic in depth, treat it as a research paper.
- If it documents a test, session, trial, or method, treat it as an experimental report.
- If it explains a tool, process, file type, sensor, workflow, or software issue, treat it as a technical note.
- If it captures a developing idea, early observation, question, or short documented thought, treat it as a research note.
- If it comes from field experience, investigation practice, or lessons learned, treat it as a field article.
- If it focuses on a location, claim, history, or case background, treat it as a case or location study.
- If it compares sources, methods, theories, claims, or equipment, treat it as a review paper.

Labels can be used to show secondary subjects such as EVP, ITC, equipment, ethics, consciousness, anomalous experience, methodology, evidence review, or environmental factors.

## Shared Writing Standard

All contributions should be scholarly but readable. Start with plain language, build context, define important terms, explain the reasoning, and be honest about what is known, unknown, unresolved, or limited.

Contributors may use images, graphs, charts, tables, video, audio, diagrams, and source links when they support the work. Media should clarify the article, not decorate it or exaggerate a claim.

## Shared Claim Standard

Use careful language. The Paranormal Initiative does not require contributors to dismiss unusual experiences, but it does require contributors to avoid overstating evidence.

Preferred language includes:

- possible
- plausible
- unresolved
- documented
- observed
- reported
- requires further review
- cannot be determined from this material alone

Avoid unsupported claims of proof, certainty, or paranormal cause.

## Shared Ethics Standard

Contributors must respect privacy, copyright, witnesses, property owners, locations, and other investigators. Private case material should not be published without permission. Outside work should be linked, cited, summarized, or quoted only within fair and responsible limits.
