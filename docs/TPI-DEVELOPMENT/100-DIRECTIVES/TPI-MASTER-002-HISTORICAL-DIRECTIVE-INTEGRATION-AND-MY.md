- The displayed workspace does not match the expected studio.
- An existing motion background is no longer visible.
- Crossroads is missing from the My Studios dropdown.

These are owner-reported production defects.

Investigate using non-destructive diagnostics.

Determine:

- Which studio ID is actually active.
- Which workspace is displayed.
- Which studio name is displayed.
- Which registry supplies My Studios.
- Whether Crossroads exists in the registry.
- Whether duplicate Crossroads identities exist.
- Whether the original motion background remains stored.
- Whether scene assignments are being loaded incorrectly.
- Whether workspace switching is crossing studio boundaries.

Do not create another Crossroads studio.

Do not overwrite or reset existing Crossroads data.
