# Directives

This directory indexes directive records without moving or duplicating the
original files. Historical source documents remain where they were created so
existing links and audit history remain intact.

These files preserve the scope and authorization that applied when each
directive ran. They are not the current commit, push, or deployment procedure.
Current operations are controlled by
`TPI-MASTER-AUTONOMOUS-AGENT-AUTHORITY.md`,
`../TPI-LOCAL-TO-PRODUCTION-RUNBOOK.md`, and, for StudioFlow,
`../TPI-STUDIOFLOW-SOURCE-TO-LIVE-WORKFLOW.md`.
