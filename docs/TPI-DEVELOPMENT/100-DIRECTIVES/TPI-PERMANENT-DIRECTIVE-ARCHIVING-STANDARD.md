# THE PARANORMAL INITIATIVE
## PERMANENT DIRECTIVE ARCHIVING STANDARD

**Classification:** Mandatory Development Governance  
**Applies To:** All TPI development agents, projects, and directives  
**Effective:** Immediately

### 1. Mandatory Historical Preservation

Every development directive issued by the project owner or authorized development coordinator must be permanently archived.

This includes:

- Original development directives.
- Directive revisions.
- Addenda.
- Recovery directives.
- Corrective instructions.
- Architecture changes.
- Deployment instructions.
- Testing and verification directives.
- Documentation governance directives.

No directive may be omitted because it was superseded, unsuccessful, or subsequently corrected.

### 2. Archive Location

Use the existing TPI development documentation structure.

The agent must inspect the current directory organization and identify the authoritative historical directive archive.

If an appropriate archive already exists, use it rather than creating a competing documentation structure.

### 3. Preserve Original Instructions

Each directive must be saved as a Markdown document.

Preserve the complete original directive text, including:

- Directive identifier.
- Title.
- Date and time issued.
- Purpose.
- Requirements.
- Acceptance criteria.
- Safety restrictions.
- Documentation requirements.

Do not summarize the directive in place of preserving its full text.

Do not silently rewrite previously issued instructions.

### 4. Separate Directives From Completion Records

Maintain a clear distinction between:

**Directive Archive:** What the agent was instructed to accomplish.

**Completion Archive:** What the agent actually implemented, tested, and deployed.

Completion records must reference the directive that authorized the work.

### 5. Maintain Historical Relationships

Each archived directive must identify relevant relationships, including:

- Original directive.
- Subsequent revisions.
- Addenda.
- Recovery orders.
- Superseding instructions.
- Related completion records.

This allows future agents to reconstruct the complete development history.

### 6. Maintain the Directive Index

Every archived directive must be entered into the authoritative directive index.

Include:

- Directive identifier.
- Title.
- Issue date.
- Current status.
- Archive location.
- Related completion records.

The index must distinguish historical completion claims from current verified implementation status.

### 7. Mandatory Agent Procedure

Before beginning implementation:

1. Read `AGENTS.md`.
2. Read the authoritative development workflow.
3. Archive the complete directive received.
4. Update the directive index.
5. Review relevant historical directives.
6. Confirm the current requirements and their dependencies.
7. Begin implementation.

After implementation:

1. Create the completion record.
2. Link it to the original directive.
3. Update affected Markdown documentation.
4. Update the directive index.
5. Commit and push the documentation.

### 8. Permanent Preservation

Historical directives must never be deleted simply because they are obsolete.

Superseded directives must be labeled accordingly.

Failed implementations must remain traceable.

Corrections must reference the original instructions.

Historical records must not be rewritten to conceal mistakes or unsuccessful development work.

### 9. Agent Independence

A future development agent must be able to enter the project without access to previous conversations and determine:

- What was requested.
- When it was requested.
- Why it was requested.
- What implementation was attempted.
- What was completed.
- What failed.
- What was corrected.
- What remains unfinished.

The Markdown documentation must provide that continuity.

### 10. Completion Requirement

A directive cannot be considered administratively complete unless:

- Its original text has been archived.
- Its index entry exists.
- Its completion record is linked, if implementation occurred.
- Relevant current-state documentation is synchronized.
- Documentation changes have been committed and pushed.

**END OF PERMANENT DIRECTIVE ARCHIVING STANDARD**
