# TPI-STUDIOFLOW-037
## ADDENDUM A — UNIFORM PRODUCTION BUTTON STYLING

**Priority:** HIGH  
**Scope:** Scenes panel visual consistency  
**Status:** Required correction before Directive 037 completion

### OBJECTIVE

Correct the inconsistent styling of the **Add Music After Intro** button and ensure all production-item buttons share the same visual dimensions and styling.

### REQUIRED CHANGES

1. Use the existing **Intro Video** button as the authoritative visual reference.

2. Apply its exact outer dimensions, background styling, border treatment, corner radius, and typography to every production-item button.

3. Replace the existing dashed-border **Add Music After Intro** presentation with the standard production-item button component.

4. Display a music-note icon using the same blue icon styling and alignment as the Intro Video button.

5. Display the primary label **Add Background Music** and secondary label **After Intro** when no track is assigned.

6. When a track is assigned, display its name while preserving the same button dimensions.

7. Ensure the Intro Video, Background Music, Scene, Countdown, Video Clip, and Outro Video buttons all use the same shared visual component or styling contract.

8. Correct unnecessary text truncation, including the currently visible **Outro Vi...** label.

9. Preserve the existing music selection, automatic playback, volume, looping, and persistence behavior.

10. Do not alter the existing production playback architecture.

### VALIDATION

Verify that:

- All production-item buttons have identical outer dimensions.
- Background Music no longer uses the old dashed-border appearance.
- Icons are consistent in size, color, and alignment.
- Standard item labels remain readable.
- Drag-and-drop functionality remains operational.
- Context menus remain functional.
- Existing automatic music playback remains unchanged.
- Per-Studio settings remain intact.
- No previously completed Directive 037 functionality regresses.

### COMPLETION REQUIREMENT

Include this correction in the Directive 037 implementation and testing records.

**Do not mark Directive 037 complete until the Scenes panel uses a consistent button design throughout.**

**END OF ADDENDUM A**
