# TPI-STUDIOFLOW-034 — ADDENDUM B
## EMERGENCY SOUNDS AND BACKGROUND MUSIC RESTORATION

**PRIORITY: CRITICAL — OWNER DIRECTIVE**

FreeBuff, the owner is dissatisfied with the current StudioFlow asset-management interface.

The Sounds and Background Music sections must be restored to their previously working functionality and appearance.

**STOP adding new features to these sections.**

### 1. RESTORE ORIGINAL SOUNDS

Locate the last verified working implementation of StudioFlow's original Sounds section in Git history.

Restore its original:

- Sound upload functionality.
- Sound playback.
- Stop Sound button.
- Volume slider.
- Existing sound selections.
- Heartbeat Fast example sound.
- Original interface organization.

Remove the redundant soundboard interface introduced by subsequent development.

Do not remove existing uploaded sound files or saved references.

### 2. RESTORE ORIGINAL BACKGROUND MUSIC

Locate the last verified working implementation of the original Background Music section.

Restore its:

- Music upload functionality.
- Music playback.
- Stop Music button.
- Volume slider.
- Existing music selections.
- Original interface organization.

Remove redundant music grids and competing playback controls.

Preserve all uploaded music and saved assignments.

### 3. PRESERVE EXISTING WORK

Do not revert the entire StudioFlow application.

Preserve:

- My Studios switching and automatic saving.
- Existing studios.
- Crossroads of the Unknown.
- Protected Intro and Outro video assignments.
- Working Video Clips functionality.
- Backup and restore improvements.
- Authentication and access controls.
- Existing motion backgrounds.

### 4. DO NOT DESTROY NINE-SLOT DATA

If the newer nine-slot audio system has already stored user media or assignments, preserve those records and files.

Do not delete the data merely because the new interface is being removed.

Any future nine-slot audio redesign must be separately approved.

### 5. VISUAL VERIFICATION

Open StudioFlow in an isolated browser session.

Verify that Sounds and Background Music resemble their original working interfaces.

Confirm:

- No duplicate Sounds sections.
- No duplicate Background Music sections.
- No overlapping controls.
- No horizontal overflow.
- Readable labels.
- Working playback.
- Working volume and stop controls.

Test in Firefox Developer Edition and Chromium.

### 6. DEPLOYMENT

Once restoration is verified:

1. Run relevant regression tests.
2. Commit the restoration.
3. Push to GitHub.
4. Deploy through the existing guarded Cloudflare workflow.
5. Verify the restored sections on production.
6. Confirm the working tree is clean.

Do not modify production studio data or media.

### 7. FINAL REPORT

Provide:

- Original Git implementation identified.
- Sounds functionality restored.
- Background Music functionality restored.
- Duplicate interfaces removed.
- Media preservation confirmation.
- Browser test results.
- Commit SHA.
- Production Worker version.
- Screenshots of the restored interface.

**FINAL REQUIREMENT:**

Restore the reliable Sounds and Background Music experience before proceeding with additional StudioFlow development.

**END ADDENDUM**
