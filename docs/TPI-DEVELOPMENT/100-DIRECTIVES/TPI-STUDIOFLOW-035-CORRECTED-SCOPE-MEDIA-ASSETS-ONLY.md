# TPI-STUDIOFLOW-035
## EMERGENCY MEDIA ASSETS RESTORATION
### CORRECTED OWNER DIRECTIVE

**PRIORITY: CRITICAL**

**SCOPE: MEDIA ASSETS NAVIGATION ONLY**

### PHASE 1 — RESTORE MEDIA ASSETS

Restore the original working layout and functionality of the **Media Assets** navigation section.

This includes only:

1. **Video Clips** — Repair the broken layout while preserving all nine slots. Intro and Outro remain protected. Slots 3–9 must have customizable names.

2. **Video Timers** — Restore the original working timer presentation and eliminate duplicate controls. Preserve the six timer configurations and existing countdown engine.

3. **Sounds** — Restore the original Sounds interface, including upload, playback, volume, Stop Sound, and existing assets.

4. **Background Music** — Restore the original Background Music interface, including upload, playback, volume, Stop Music, and existing assets.

5. **Motion Backgrounds** — Preserve the existing functionality and restore any affected presentation.

**Do not delete the newer nine-slot sound or music data.** Preserve it for proper integration during Phase 2.

### PHASE 2 — MEDIA ASSETS RECONSTRUCTION

**Planning only until the owner approves Phase 1.**

Once the original Media Assets interface is restored:

- Integrate nine sound-effect slots into the original Sounds section using **Option B: compact horizontal rows**.
- Integrate nine music slots into the original Background Music section using the same layout.
- Maintain nine video slots with properly sized previews.
- Maintain six timer configurations in one unified interface.
- Plan attractive, customizable placards separately from video clips.

There must be no duplicate Sounds, Background Music, or Timer sections.

### STRICT SCOPE PROTECTION

**DO NOT MODIFY:**

- StudioFlow Home.
- My Studios navigation.
- Studio switching or automatic saving.
- Recording functionality.
- Scene management.
- Broadcast controls.
- Podcast settings.
- Authentication.
- Admin Panel.
- Feed or Community.
- Other website sections.
- Existing studio data or media.

Only make changes outside Media Assets if an essential shared dependency requires it; document and minimize any such change.

### TESTING AND DEPLOYMENT

Verify the corrected Media Assets interface visually and functionally in Firefox Developer Edition and Chromium.

Test at the owner's actual sidebar width.

Once Phase 1 passes:

1. Commit.
2. Push.
3. Deploy using the existing guarded Cloudflare workflow.
4. Verify the live Media Assets interface.
5. Confirm the working tree is clean.

Do not start Phase 2 until the owner approves the restored Media Assets interface.

### FINAL OBJECTIVE

**Restore only the Media Assets navigation section to a stable, clean, working condition without disturbing the rest of StudioFlow.**

**END DIRECTIVE**
