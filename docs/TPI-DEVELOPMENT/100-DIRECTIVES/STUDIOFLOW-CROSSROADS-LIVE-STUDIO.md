- Whether its asset ID is valid.
- Whether its media URL resolves.
- Whether its R2 object exists.
- Whether its scene assignment is persisted.
- Whether the correct scene is active.
- Whether the video element is created.
- Whether the playback bridge is functioning.
- Whether the canvas rendering layer is functioning.
- Whether the video is hidden behind another layer.

- Whether the recent deletion cleanup is affecting playback.

Check browser console errors and network requests.

Distinguish between:

MISSING ASSET
MISSING SCENE ASSIGNMENT
INCORRECT STUDIO IDENTITY
FAILED MEDIA LOADING
FAILED VIDEO PLAYBACK
FAILED CANVAS RENDERING
