# Michigan Haunted Location Directory

Date: 2026-11-17  
Status: Implemented locally; release verification follows the maintained TPI runbook.

## What changed

Michigan now has a 20-entry public location-reference page at
`/haunted-location-directory/michigan.html`. It follows the established
directory presentation and interaction model: searchable entries, expandable
research details, source links, location data, activity reports, access notes,
and a clear distinction between documented history and reported paranormal
claims.

The directory index and the public haunted-locations page now list Michigan as
a started state page with 20 entries. The displayed directory totals are 25
started state pages and 463 imported location entries.

## Verification standard

“Verified” here means that the entry has a traceable public source for its
history, location, or reported claim tradition. It does not mean that a
haunting has been proven. Claims are labeled as reported, folklore, or
investigative accounts, and entries retain access, privacy, safety, and
operator-permission cautions.

The source mix includes Detroit historical and tourism references, official
site histories, Michigan tourism research, Mackinac Island tourism material,
Petoskey-area historical research, lighthouse and museum sources, and
published investigative coverage. Old Presque Isle is intentionally marked as
a lower-strength folklore lead because its museum source records the rumor but
does not endorse it as established fact.

## Follow-up

The page is an initial research-lead set. Future additions should preserve the
same evidence ledger: documented site history, specific claim source, exact
location, access status, research classification, and a note separating
ordinary environmental explanations from unexplained reports.
