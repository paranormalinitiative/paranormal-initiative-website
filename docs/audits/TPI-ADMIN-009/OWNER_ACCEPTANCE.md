# TPI-ADMIN-009 — Owner acceptance

The owner can review the protected live preview without sharing credentials:

1. Sign in normally at `https://paranormalinitiative.com` with the authorized
   owner/admin account.
2. Open `https://paranormalinitiative.com/admin-center-preview/`.
3. Review Dashboard, Analytics, Member Directory/detail tabs, Community,
   Reactions, Reports, Contributors, Teams, Creators, Education, Events,
   Notifications, Platform Health, Security, Audit Logs, and System Settings.
4. At desktop, tablet, and mobile widths, check sidebar navigation, tables,
   dialogs, long labels, loading/error states, and the six TPI themes.
5. Use only disposable or safe records for approve/reject, report resolution,
   block/reactivate, invite, and settings checks.
6. Confirm `/admin-panel` remains the existing Administration Center and
   `/live-video` remains Coming Soon.

Report visual defects, missing data, broken controls, or unexpected errors.
Owner acceptance is not claimed until the owner performs this review in an
authenticated session.
