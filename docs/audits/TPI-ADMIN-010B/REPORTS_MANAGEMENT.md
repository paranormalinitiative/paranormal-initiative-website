# Reports Management

Status: **WORKING FOR SUPPORTED TYPES; PARTIAL OVERALL**.

The existing centralized queue now supports bounded metadata filtering by
report type, status, date range, search, sort, direction, and pagination.
Supported types are video and messenger reports. A protected detail endpoint
returns the supported metadata and bounded audit history for one report.

Community post/comment reports are not claimed because no supported backend
contract exists. Unsupported categories are not fabricated.
