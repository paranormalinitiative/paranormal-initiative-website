# Administration navigation matrix

| Group | Required entries | Preview status |
| --- | --- | --- |
| Dashboard | Overview, Analytics, Activity | Integrated |
| Members | All Members, Roles & Permissions, Account Restrictions | Members integrated; two capability boundaries |
| Community | Overview, Posts & Comments, Reports & Moderation, Moderation History | Posts/comments/audit integrated; unified reports unavailable |
| Creators | Directory, Founding 50, Studio Access, Channels | Existing-system/capability boundaries |
| Content & Publishing | TPI Videos, Education Center, Contributors, Teams, Events | Existing-system/capability boundaries |
| System | Notifications, Platform Health, Security, Audit Logs, Settings | Audit/security integrated; remaining existing-system boundaries |

Repeated `Community Overview` and `Posts & Comments` entries intentionally
resolve to the same existing Community Feed resource, not duplicate APIs.
