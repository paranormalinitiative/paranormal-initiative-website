# Administration Center design system

The preview uses a restrained TPI operations palette: deep navy navigation,
cool blue primary actions, high-contrast white cards, muted slate metadata,
and green/amber status badges. It uses existing TPI language such as
Administration, protected session, members, audit activity, Creator Studio,
and System settings.

Layout primitives are responsive CSS grid/flex layouts. shadcn/ui source
components own interaction states and focus rings. Lucide icons are used for
navigation and status affordances. The preview does not alter the public
site's typography, theme settings, or member shell.
