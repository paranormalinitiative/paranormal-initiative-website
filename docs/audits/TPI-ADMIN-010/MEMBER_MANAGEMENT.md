# TPI-ADMIN-010 — Member Management

Status: **WORKING WITH LIMITATIONS**. Existing protected APIs provide member
search, filtering, sorting, pagination, member details, activity tabs, and
bounded post/comment/reaction activity. Private messages, passwords, session
tokens, and unrelated personal data are excluded.

Account restriction controls preserve the existing capability boundary and
confirmation flow. No owner/admin role changes or consequential production
member mutations were performed during this audit.
