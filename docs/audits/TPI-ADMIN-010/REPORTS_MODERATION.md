# TPI-ADMIN-010 — Reports and Moderation

The existing protected reports workspace provides a bounded metadata queue,
safe search, pagination, supported resolution controls, and moderation-history
records. Private Messenger bodies and unsupported private evidence remain
excluded.

Status: **PARTIAL**. The supported report tables do not provide a general
community-post report contract, so post detail explicitly reports that this
capability is unavailable. No production report or member record was mutated.
The full WHO/WHAT/WHERE/WHY/WHEN/ACTION matrix is complete only for fields
present in the existing supported tables.
