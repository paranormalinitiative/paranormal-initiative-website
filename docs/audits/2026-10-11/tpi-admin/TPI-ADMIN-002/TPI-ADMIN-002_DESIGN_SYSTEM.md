# TPI-ADMIN-002 Design System

The existing TPI tokens, typography, colors, border radii, cards, portal
buttons, and themes are reused. Added administrative primitives are CSS/HTML
patterns rather than a new component framework: grouped sidebar navigation,
filter bars, data tables, status badges, chart cards, empty states, and the
existing audit/member detail surfaces.

Reduced-motion styling, contained table overflow, mobile stacking, and visible
focus remain part of the page's existing shell behavior.
