# TPI-ADMIN-002 Reference Analysis

Refine was used as the functional information-architecture reference: dense
resource navigation, filters, server-backed tables, detail-oriented admin
workflows, explicit loading/empty/error states, and permission-aware actions.

shadcn/ui was used as the visual reference: restrained cards, status pills,
filter bars, compact data tables, visible focus, and responsive composition.

Neither framework was installed or migrated. The implementation stays within
TPI's existing HTML, CSS, browser JavaScript, Worker, and D1 architecture.
