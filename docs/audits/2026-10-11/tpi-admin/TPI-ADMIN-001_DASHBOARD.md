# TPI-ADMIN-001 Dashboard

The Overview view reports real D1-backed values for members, visible community
posts, published videos, published events, unread member notifications, and
approved teams. Optional source failures are shown as `Unavailable`; the UI
does not substitute fabricated zeros.

The program-status panel reports scraper-run availability and source provenance.
The audit preview links to the full bounded audit view. Refresh re-queries the
protected endpoints without changing data.
