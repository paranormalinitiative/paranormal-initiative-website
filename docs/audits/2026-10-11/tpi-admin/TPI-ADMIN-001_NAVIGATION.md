# TPI-ADMIN-001 Navigation

The existing admin panel now presents a dedicated left-side navigation with:

Overview, Analytics, Members, Community, Moderation, Creators, Founding 50,
Creator Studio, TPI Videos, Content, Events, Notifications, System Health,
Security, and Audit Logs.

The navigation is responsive: it becomes a wrapped control row on smaller
screens. It uses hash navigation inside the existing protected page, preserving
the existing member search, invitations, moderation, and advanced-settings
destinations. It does not change `/studio/`, `/live-video`, or public labels.
