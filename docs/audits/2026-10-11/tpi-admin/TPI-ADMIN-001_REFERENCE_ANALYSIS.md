# TPI-ADMIN-001 Reference Analysis

The implementation uses the requested references as patterns, not as imported
frameworks or copied branding.

- [Refine](https://refine.dev/) informed the resource-oriented grouping of
  members, community, content, events, and system operations.
- [shadcn/ui dashboard blocks](https://ui.shadcn.com/blocks?category=dashboard)
  informed the responsive sidebar, metric cards, status rows, and data-first
  composition. The current TPI site remains dependency-free HTML/CSS/JS.
- [shadcn/ui sidebar guidance](https://ui.shadcn.com/docs/components/base/sidebar)
  informed the collapsible/responsive navigation intent; the TPI implementation
  uses the existing site shell and CSS tokens.
- [Discourse](https://www.discourse.org/) remains a secondary moderation and
  community-operations reference only. The retired Forum system is not restored.

No framework replacement, package installation, or external admin service was
introduced.
