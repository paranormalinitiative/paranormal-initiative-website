# TPI-UI-003 Administration Alignment

The Administration sidebar remains the approved reference and its navigation
items and responsive menu behavior are preserved.

The Administration main column now explicitly owns the width of its direct
hero, overview, statistics, chart, management, and lower dashboard sections.
The existing three-column wide layout, two-column intermediate layout, and
single-column narrow layout remain flexible through route-scoped rules. The
Current Snapshot metrics and lower Program Status/Administrative Audit panels
therefore share the same main content edges and gutters as Operations Overview.

No administrative API, filtering, pagination, authorization, or data value was
changed.
