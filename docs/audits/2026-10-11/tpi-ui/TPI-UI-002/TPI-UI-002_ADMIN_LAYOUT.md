# TPI-UI-002 Administration Layout

The existing Administration Center remains a two-column workspace: its
internal sidebar remains one dedicated navigation surface and the main area
uses the remaining width. Main dashboard sections, statistics, charts, tables,
filters, and management controls remain unchanged.

At wide desktop widths, metrics/charts use three columns. At intermediate
widths they use two columns, and at mobile widths they stack. The existing
sidebar collapse behavior at its established breakpoint remains intact.
