# TPI-UI-002 Settings Layout

The existing Settings Center remains a two-column layout with its generated
Settings navigation/search on the left and the existing settings panels on the
right. The dedicated route no longer inherits the older 1,440px outer limit;
the workspace may use up to 1,600px while individual cards and forms remain
readable.

The existing account identity, role text, Sign Out control, settings categories,
search, theme controls, forms, and save paths remain in place. The profile
header spacing is compacted and reflows as a stacked block on narrow screens.
