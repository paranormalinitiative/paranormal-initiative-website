# TPI-UI-002 Accessibility

The refinement preserves semantic workspace headers, navigation landmarks,
existing focus styles, keyboard-focusable links/buttons, and reduced-motion
handling. It does not hide account, Messenger, Sign Out, or Back to TPI
functionality at smaller widths.

Automated source checks pass for scoped landmarks and controls. Authenticated
keyboard, screen-reader, zoom, contrast, and rendered focus traversal remain
owner-assisted verification items rather than being marked passed.
