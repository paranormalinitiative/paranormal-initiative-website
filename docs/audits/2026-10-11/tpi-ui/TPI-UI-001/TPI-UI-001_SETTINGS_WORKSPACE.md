# TPI-UI-001 Settings Workspace

`/member-dashboard` and `member-dashboard.html` continue to use the existing authenticated settings implementation and `data-settings-*` hooks. The Settings Center retains its generated settings navigation, search, panels, theme controls, account controls, notifications controls, and responsive settings layout.

The duplicate generic member sidebar and public website chrome are suppressed only on this workspace route. The new header identifies the TPI Settings Center and provides `Back to TPI` to `member-home.html`.

Authenticated owner/member browser review remains required for final visual acceptance; settings mutations were not exercised by this layout-only change.
