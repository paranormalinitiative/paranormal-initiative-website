# TPI-UI-001 Administration Workspace

`/admin-panel` and `admin-panel.html` continue to use the existing server-side protected route and `data-admin-panel` behavior hooks. The Administration Center retains its internal sidebar, section navigation, admin data views, refresh actions, legacy controls, and Advanced settings link.

The duplicate generic member sidebar is suppressed only on this workspace route. The new header identifies the protected Administration Center and provides `Back to TPI` to `member-home.html`.

Authenticated owner/admin browser review remains required for final visual acceptance; no credentials were invented or bypassed.
