# TPI-UI-001 Accessibility

The implementation uses semantic `header`, `nav`, `main`, and link elements already present in the workspaces. Each new workspace header has an accessible label, visible keyboard-focusable `Back to TPI` link, and readable text at narrow widths. Existing admin/settings landmarks and focus styles are preserved.

Automated source checks confirm both dedicated navigation landmarks and return controls exist. Screen-reader and keyboard traversal in an authenticated browser remain pending owner review.
