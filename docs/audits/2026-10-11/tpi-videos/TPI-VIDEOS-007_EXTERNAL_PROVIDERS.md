# TPI-VIDEOS-007 External Providers

The existing approved provider catalog remains the source of truth:

- YouTube
- Rumble
- Odysee
- Dailymotion
- Internet Archive

YouTube, Rumble, and approved Dailymotion embed-shaped URLs may render in an
iframe. Odysee and Internet Archive currently use an external-watch fallback
because no approved embed source is generated by the existing validator.

Arbitrary iframe hosts, `javascript:` URLs, HTTP URLs, credential-bearing URLs,
and malformed provider paths are rejected by the client resolver in addition to
the existing server-side validation.
