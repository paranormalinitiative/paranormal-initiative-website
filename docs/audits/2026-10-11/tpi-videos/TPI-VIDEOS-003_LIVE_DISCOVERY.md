# TPI-VIDEOS-003 Live Discovery

The discovery API can filter authored records by `is_live`. Approved scraped records are excluded from a `live=true` request because external scraped metadata is not proof of an active TPI broadcast. There were no public authored live rows in the production baseline.

Public `/live-video` remains Coming Soon. Actual provider live playback, scheduling feeds, and public livestream launch remain NOT YET VERIFIED and were not introduced by this batch.
