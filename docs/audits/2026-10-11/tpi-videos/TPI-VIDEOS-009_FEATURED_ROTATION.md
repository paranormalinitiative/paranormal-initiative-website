# TPI-VIDEOS-009 Featured Rotation

The permanent featured section remains data-driven and prominent. Live items take precedence. Otherwise an eligible published featured item is chosen; if no item is explicitly featured, the catalog falls back to the first non-live item. The last selected key is stored only in the visitor's browser so a refresh can choose a different eligible item without changing production data. A single eligible item is allowed to repeat.
