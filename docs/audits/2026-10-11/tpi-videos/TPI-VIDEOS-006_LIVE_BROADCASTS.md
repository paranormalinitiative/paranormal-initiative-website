# TPI-VIDEOS-006 Live Broadcasts

The public `/live-video` route remains Coming Soon and was not launched.
Unverified live playback is excluded from public broadcast discovery by the
existing API filters. The local RTMP receiver test verified valid encoded
audio/video transport, but it is not proof of a public provider broadcast.

Verified lifecycle states include scheduled/upcoming, ready, live metadata,
ended, cancelled, unpublished, and replay metadata in the local D1 suite.
Live provider status, public viewer playback, RTMPS, multi-destination
delivery, and long-duration streaming remain **NOT VERIFIED**.

No public stream, stream key, provider account, or production broadcast was
created by this audit.
