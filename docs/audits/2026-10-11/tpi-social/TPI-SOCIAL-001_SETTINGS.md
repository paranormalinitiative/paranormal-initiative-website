# Settings

Settings IA is generated by `member-settings.js` and groups account, profile,
privacy/safety, creator/content, preferences, data/support, and monetization.
Connected controls include themes, personalization, notifications, blocked users,
and existing profile/content links. Explicitly disabled controls are labeled as
not connected rather than pretending to work.

The API/SQLite phase passed. The source test defines deep links, search, four
viewport sizes, no overflow checks, and rollback checks; its browser phase is
BLOCKED by missing Playwright.
