Visual ITC Research

ITC Visual Studio

ITC Visual Studio is a browser-based visual ITC research workstation for researchers exploring water, steam, reflective surfaces, light movement, image review, and visual ITC session documentation. It runs directly in your web browser with no download or installation required. The goal is careful capture, comparison, and review rather than automatic interpretation.

Launch ITC Visual Studio Software Use Terms

Current Version

Browser Edition — Live. ITC Visual Studio is now available directly through The Paranormal Initiative website. No application download or installation is required.

Update Path

Browser-Based Updates. ITC Visual Studio is updated periodically through The Paranormal Initiative website. Updates are delivered through the browser application, so users do not need to download or install separate software updates.

Research Position

ITC Visual Studio is designed to support visual ITC and scrying experimentation, frame-by-frame review, documentation, and the organization of potential evidence candidates. Interpretation remains with the researcher, allowing observations and findings to be evaluated within the context of each individual experiment.
