# TPI Case-File Photos

These are the local case-file copies served by the Haunted Location Directory.
Local hosting makes the site independent of remote thumbnail delivery; it does
not transfer the original photographer's copyright or remove attribution and
license obligations.

- `forepaughs-restaurant.png` — local exact-building reference supplied for TPI's case file. The associated source record is <https://commons.wikimedia.org/wiki/File:Joseph_Forepaugh_Mansion,_Exchange_Street,_Irvine_Park,_Saint_Paul,_MN.jpg>; retain the recorded attribution and verify reuse rights before redistributing outside TPI.
- `forepaughs-restaurant-case-file.jpg` — stylized TPI case-file treatment derived from the exact-building reference. It is labeled as a treatment in the directory and must not be presented as an unedited documentary photograph.

Do not replace an exact location photograph with an AI-generated landmark
likeness. If a location does not have a verified exact image and reuse record,
the directory must keep its **Exact case-file photograph pending** state.
